How to use CalcIQ

Keys

T+
Adds tax to an amount. (T means tax)
Example: 100, T+, = → 112
T-
Removes tax from a price that already includes it.
Example: 112, T-, = → 100
√
Gives the square root of the number you typed.
Example: 81, √ → 9
%
Finds a percent of a number.
Example: 200, %, 15, = → 30
xy
Raises a number to a power.
Example: 2, xy, 3, = → 8
mod
Gives the remainder after dividing.
Example: 10, mod, 3, = → 1
±
Switches between positive and negative.
Example: 5, ± → -5
⌫
Deletes the last digit.
Example: 125, ⌫ → 12
C
Clears everything.

Tax rate

The default rate is 12% (Philippine VAT). To use a different rate, press T+ or T-, type the rate, then press =.
Example: 100, T+, 5, = → 105

History

The note on the left shows your latest calculations, newest first.

Good to know

  • You can't divide by zero or take the square root of a negative number. The display shows an error instead.
  • Each number can have only one decimal point.
